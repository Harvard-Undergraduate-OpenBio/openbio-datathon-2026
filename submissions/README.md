# Submissions

Track 1 teams commit their final work here. See [Track 1: Submit](../track-01/4-submit.md) for what to include.

Track 2 teams submit through their own private team repository instead. See [Track 2: Submit](../track-02/4-submit.md).

## Structure

Create a folder for your team:

```
submissions/
└── your-team-name/
    ├── notebook.ipynb          # Your reproducible analysis notebook
    ├── figures/                 # Two to four figures as PNG or PDF
    │   ├── fig1_*.png
    │   ├── fig2_*.png
    │   ├── fig3_*.png
    │   └── fig4_*.png
    ├── final-submission.md      # Completed final submission template
    ├── hypothesis-card.md       # Completed hypothesis card
    └── analysis-plan.md         # Your analysis plan
```

## How to Submit

1. Copy the templates from [`track-01/templates/`](../track-01/templates) into your team folder.
2. Fill them in.
3. Run your analysis notebook and save figures.
4. Commit everything to your branch.
5. Open a pull request titled `Submission: [Your Team Name]` before the deadline.

## Rules

- One notebook or script that runs top-to-bottom.
- Two to four figures (PNG at 300 DPI or PDF).
- One to two page written interpretation.
- One completed hypothesis card.
- Cite all data sources.
- State limitations clearly.
