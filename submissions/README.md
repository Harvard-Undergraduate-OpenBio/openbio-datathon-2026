# Submissions

This directory is where teams commit their final submission materials.

## Structure

Create a folder for your team:

```
submissions/
└── your-team-name/
    ├── notebook.ipynb          # Your reproducible analysis notebook
    ├── figures/                 # 2-4 figures as PNG or PDF
    │   ├── fig1_*.png
    │   ├── fig2_*.png
    │   ├── fig3_*.png
    │   └── fig4_*.png
    ├── final-submission.md      # Completed final submission template
    ├── hypothesis-card.md       # (Track 1) Completed hypothesis card
    └── analysis-plan.md         # Your analysis plan
```

## How to Submit

1. Copy the templates from `../templates/` into your team folder.
2. Fill them in.
3. Run your analysis notebook and save figures.
4. Commit everything to your branch.
5. Open a pull request titled `Submission: [Your Team Name]` before the deadline.

## Rules

- One notebook or script that runs top-to-bottom.
- 2-4 figures (PNG at 300 DPI or PDF).
- 1-2 page written interpretation.
- One completed hypothesis card (Track 1) or intervention proposal (Track 2).
- Cite all data sources.
- State limitations clearly.
