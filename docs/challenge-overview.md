# Challenge Overview

The OpenBio 2026 Datathon features a computational biology track. Participants select a team and work in groups of 2-4.

## Track 1: Computational Biology

**Focus:** Maternal-fetal cell-cell communication in preeclampsia using single-cell RNA-seq.

Teams will:
1. Load an OpenBio-provided annotated single-cell object (`.h5ad` or Seurat `.rds`).
2. Inspect metadata and cell-type annotations.
3. Select a biologically coherent sender-receiver comparison.
4. Run or reproduce a cell-cell communication analysis.
5. Compare disease and control interaction patterns.
6. Produce 2-4 figures and a prioritised list of candidate interaction programs.
7. State one testable follow-up hypothesis and its limitations.

## Judging

See the [submission rubric](submission-rubric.md) for scoring criteria.

## Responsible Data Use

- Do not redistribute raw datasets. Use download scripts and manifests.
- Cite all data sources in your submission.
- Clearly state limitations of observational inference.
