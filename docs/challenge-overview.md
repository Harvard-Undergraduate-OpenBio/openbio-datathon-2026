# Challenge Overview

The OpenBio 2026 Datathon features one computational biology track. Teams of two to four work together.

## Track 1: Computational Biology

Teams compare gene activity in placentas from preeclampsia and control pregnancies, then use reference data to ask which placental cell types may be involved.

- Core: bulk RNA-seq of 30 villous-tissue samples (GSE203507)
- Optional extension: donor-by-cell-type pseudobulk from 26 donors (Admati/Skarbianskis)
- Interpretation: the Zeisel/Admati gene browser plus linked reference atlases
- Starter notebooks: R and Python scaffolds for loading and checking the data

Read the [participant guide](track-1-computational-biology/README.md), then pick from the [starter questions](track-1-computational-biology/research-questions.md).
