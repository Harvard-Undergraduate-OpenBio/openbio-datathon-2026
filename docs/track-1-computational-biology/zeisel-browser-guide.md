# Zeisel Browser Guide

[![Browser](https://img.shields.io/badge/Tool-Zeisel_Browser-0fe995?style=flat-square)](https://storage.googleapis.com/www_zeisellab/PE_web/pe_web_test_v1.html)
[![Marker Matrix](https://img.shields.io/badge/Data-Marker_Matrix-13deba?style=flat-square)](../../data/track-01/interpretation/track01_marker_matrix.csv)

The Zeisel lab gene browser shows expression of genes across placental cell classes in the Admati and Skarbianskis preeclampsia single-cell dataset. Use it to localize genes from your analysis to the cell types that may carry them.

## Permitted uses

- Localize three to six genes from your analysis to broad placental cell classes.
- Support a hypothesis about which cell class carries a program you found in bulk data.
- Compare expression patterns between preeclamptic and control samples as shown in the browser.
- Explore candidate genes for a proposed follow-up experiment.

## Prohibited uses

- Do not treat browser output as validation of a bulk result.
- Do not use the browser as an answer key or a substitute for your own analysis.
- Do not report browser screenshots as quantitative evidence.
- Do not reprocess the underlying raw data through the browser.

## Fallback

If the browser is unavailable during the event, use the marker matrix in the Track 01 data package together with the GSE198373 and HCA reference datasets linked in the [data catalog](data-catalog.md).
