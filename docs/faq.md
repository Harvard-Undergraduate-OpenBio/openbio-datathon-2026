# FAQ

## General

**Who can participate?**
The datathon is open to undergraduate students at Harvard and affiliated institutions. Teams of 2-4 are recommended.

**Do I need prior bioinformatics experience?**
Track 1 is designed to be accessible to beginners with some programming background. Starter notebooks and a processed dataset are provided. Advanced participants can extend the analysis.

**What should I bring?**
A laptop with Python or R installed. We provide environment files for easy setup.

## Track 1

**Do I need to download the raw datasets?**
No. OpenBio provides processed, annotated challenge objects (`.h5ad` and/or `.rds`). Raw data links are in the [data catalog](track-1-computational-biology/data-catalog.md) for reference.

**Which communication tool should I use?**
You may use any tool (CellChat, CellPhoneDB, LIANA, NicheNet). The starter notebook provides a baseline using one tool. We encourage comparing results across methods if time permits.

**Can I use additional datasets?**
Yes, but you must cite them and ensure they are publicly available. The datasets in the data catalog are the recommended starting point.

## Submissions

**What format should my submission be?**
A reproducible notebook or script, 2-4 figures, a brief written interpretation, and a completed hypothesis card. See the [templates](../templates/) folder.

**How are submissions judged?**
See the [submission rubric](submission-rubric.md) for scoring criteria.
