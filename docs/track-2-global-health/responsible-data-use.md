# Track 2: Responsible Data Use

## DHS Program Data

- **Never store DHS microdata in this repository.** Only derived, aggregated, non-identifiable datasets may be distributed.
- DHS Program data is subject to registration, approval, and redistribution restrictions.
- OpenBio must obtain approval before the datathon and distribute only permitted derived data.
- Provide a reproducible extraction script so participants understand how derived data was created.

## World Bank and WHO Data

- These are public data sources. Cite the original source.
- Follow each source's data use terms.

## General Principles

- **Do not infer missing data.** If a country or region lacks data, mark it as missing.
- **Cite all data sources** in your submission.
- **Respect privacy.** Do not attempt to re-identify individuals from aggregated data.
- **Be transparent** about limitations of country-level analysis (ecological fallacy, data gaps, comparability issues).
